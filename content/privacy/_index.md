We build software that respects you. Across all Select Distinct apps:

- **No accounts.** No sign-up, no identity to hand over.
- **No analytics tracking you.** No advertising identifiers, no telemetry pipelines.
- **No selling data.** Ever. There is no data to sell.

Each app makes its own specific promises, because each app works differently.
